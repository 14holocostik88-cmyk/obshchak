Проект «Общак»

Проект «Общак» предоставляет возможность создания собственных VPN-подписок на основе приобретённых подписок сторонних VPN-сервисов.

Принцип работы

Пользователь устанавливает панель управления на собственный сервер, имеющий статический IP-адрес. После этого появляется возможность импорта JSON-файлов конфигураций из приложений Happ/Incy. Таким образом, приобретённая подписка на сторонний VPN-сервис может быть использована всеми пользователями создаваемого VPN.

Целевая аудитория и назначение

Возникает вопрос: для кого предназначен данный проект и какова его необходимость, учитывая наличие решений 3x-ui и Remnawave?

При оплате исключительно сервера и подписки на сторонний VPN-сервис появляется возможность реализации собственной подписки неограниченному числу пользователей. Вследствие особенностей Remnawave или Happ, подключение пользователей к вашей подписке не учитывается как новое подключение.

Вопросы безопасности

Возможен ли несанкционированный доступ: не смогут ли третьи лица скопировать JSON-файл из подписки вашего VPN и использовать его без оплаты?

Нет, подобное исключено. В панели управления автоматически отключена возможность просмотра JSON-файлов конфигурации, поэтому пользователи вашего VPN не смогут получить к ним доступ.

Примечание

Автор заранее приносит извинения за возможные недоработки проекта. В ближайшее время планируется добавление бота для продаж, что позволит ограничиться вставкой токена Telegram-бота без необходимости самостоятельной разработки.
