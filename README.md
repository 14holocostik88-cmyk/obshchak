Проект "Общак" позволяет вам создавать свои VPN подписки используя купленные вами подписки чужих vpn.
-Как работает?
Вы устанавливаете панель на свой сервер со статичным ip адресом, после чего можете импортировать json файлы конфигураций из happ/incy, 
т.е. вашей подпиской(подпиской на другой vpn) будут пользоваться все юзеры вашего vpn.
-Кому это надо? Зачем вообще? есть же 3x-ui и remnawave.
Оплачивая лишь сервер и подписку на чужой vpn свой вы можете продавать людям сколько захотите, из-за бага remnawave или happ подключения к вашей
подписке ваших же юзеров не считается за новое подключение.
-А разве другие люди не могут точно также как я скопировать json из подписки моего vpn и использовать без оплаты? 
Нет, в панели автоматически удалена возможность просматривать json файлы конфигурации, так что пользователи вашего vpn не смогут этого сделать.
